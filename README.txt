Clip Studio

This app embeds YouTube videos for preview and exports clips from uploaded source files that you own or are authorized to edit. It does NOT extract/download arbitrary YouTube streams.

Windows:
1. Install Node.js and FFmpeg (add ffmpeg to PATH).
2. Open this folder in Command Prompt.
3. npm install
4. npm start
5. Visit http://localhost:3000

YouTube link input provides an embedded preview only. Upload your authorized source video for trimming/export. 1440p (2K) and 2160p (4K) options are available.
